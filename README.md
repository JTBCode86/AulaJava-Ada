# ☕ Curso de Java - Ada Tech

Este repositório destina-se a armazenar os códigos, exercícios, projetos práticos e notas de estudo desenvolvidos durante o curso de aprendizado e evolução na linguagem **Java**, ministrado pela **Ada Tech**.

---

## 📌 Sobre o Repositório

O objetivo deste projeto é registrar a evolução contínua dos conceitos fundamentais aos avançados do ecossistema Java, servindo como guia de estudos, histórico de aprendizado e portfólio prático.

---

## 🛠️ Tecnologias e Ferramentas

* **Linguagem:** Java (JDK 17+)
* **IDE Recomendada:** IntelliJ IDEA / Eclipse / VS Code
* **Gerenciador de Dependências:** Maven / Gradle
* **Controle de Versão:** Git & GitHub
